# Cue Metadata

Every cue should include:

-   Title
-   Time In
-   Time Out
-   Duration
-   Scene
-   Narrative Function
-   Usage
-   Instrumentation
-   Mood
-   Master filename
-   Stem folder
-   BMI registration status
-   Cue sheet status
-   Delivery status
-   Revision history

# Naming Convention

Good examples:

-   Dark Awaits - Spirits Still Around
-   Dark Awaits - Family Investigation
-   Dark Awaits - Mystic Bell Ambience

Avoid generic names such as:

-   Cue1
-   Drone3
-   FinalFINAL.wav

# Delivery Checklist

## Before Delivery

-   Final mixes exported
-   Masters exported
-   Stems exported
-   Metadata verified
-   Cue sheet updated
-   Contracts archived
-   Rights verified

## After Delivery

-   Cue sheet submitted
-   Broadcast confirmed
-   BMI records verified
-   Royalty tracking started

------------------------------------------------------------------------

# Spotting Philosophy

Record not only *where* music begins, but *why* it begins.

Document editorial purpose, dramatic intent, pacing decisions, and how
silence is used. Preserve the reasoning behind every cue.

------------------------------------------------------------------------

# AI Operating Instructions

AI assistants may:

-   Generate cue sheets
-   Draft publishing paperwork
-   Verify metadata
-   Detect missing information
-   Generate delivery manifests
-   Summarize projects

AI assistants must never:

-   Invent metadata
-   Change ownership
-   Rename cues
-   Overwrite historical records

without explicit approval.

# Guiding Principle

Creative work is temporary.

Administrative memory should be permanent.

Every score should remain understandable years later:

-   Why it exists
-   Where it appears
-   How it evolved
-   What rights exist
-   What was delivered
-   What royalties it generated
