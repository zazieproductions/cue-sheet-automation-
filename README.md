# cue-sheet-automation-

I actually think this is an excellent use of GitHub—not because Git is the obvious tool for cue sheets, but because you're creating a long-term institutional memory for Zazie Productions. Every score becomes reproducible, searchable, and auditable.
I would treat it almost like a composer's production operations manual rather than just a folder of cue sheets.
Here's how I'd write the README.
Zazie Productions — Music Administration & Cue Library
Private operational repository for music publishing, cue sheet management, television scoring, and performance royalty administration.

Purpose
This repository serves as the canonical source of truth for all television, film, documentary, podcast, and commercial music administered under Zazie Productions.
Its goals are to:
- Maintain accurate cue sheet records
- Archive production metadata
- Track BMI registrations
- Preserve composer intent
- Store delivery history
- Document licensing information
- Support future royalty collection
- Create reproducible administrative workflows
This repository is private and functions as an internal publishing archive.
